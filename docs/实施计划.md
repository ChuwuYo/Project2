# FER 期末项目 · 实施计划 v1

> **说明（2026-11-04）**：这是动手写代码之前的实施计划，保留下来作为过程记录，里面有些文件名、命令和做法后来改了，**不要照着它运行**。实际代码和用法以 `README.md`、`docs/项目代码详解.md`、`docs/训练过程说明.md` 为准。主要变化：
> - 没有 `select.py`、`plot.py`、`data_check.py`、`stats.json`、`decision.json`：TTA 决定写在每个模型的 `summary.json`，曲线由 `train.py` 自己画，数据检查是 `check_data.py`，MEAN/STD 是 `dataset.py` 里的常数（由 `tests` 重新计算核对）。
> - 评估命令是 `python evaluate.py`（读 `final_runs.txt` 中的 6 个模型），不是 `--ckpt runs/final/best.pt`；模型目录是 `runs/<实验>_s<种子>/`。
> - 自己训练用 `python train.py --exp A1 --seed 0 --out runs_local`。
> - 最终方案是 A1、A2 各 3 个种子的六模型集成，PrivateTest 73.11%。

基于《期末项目通知》PDF 与《人脸表情识别（FER）技术方案》（2026-10-27 初稿）细化。验收：2026-12-01 课上。

## 3. 数据层

- 首次读取 CSV 后缓存为 `data/fer2013.npz`（uint8，约 80 MB），之后秒级加载，也方便上传到 Colab。
- 检查项：三个子集数量 28709/3589/3589；emotion ∈ 0~6；每行 2304 个像素；类别分布（Disgust 436 / Happy 7215）；样例网格。
- 增强（仅训练集）：水平翻转、RandomAffine(±10°, 平移 10%, 缩放 0.9~1.1)、可选 RandomErasing。验证/测试只做 ToTensor+Normalize。
- Windows 兼容：pathlib 路径，`num_workers` 默认 Windows 0、Linux 2。

## 4. 模型与训练

- 主模型：ResNet18 从头训练；conv1 改 3×3/stride1 单通道，去 maxpool，fc 前加 Dropout(0.4)。约 1100 万参数。
- 备选（集成用）：VGG 风格 4 卷积块网络。
- 训练：SGD(lr 0.01, momentum 0.9, nesterov, wd 5e-4)，ReduceLROnPlateau(监控 PublicTest acc, factor 0.5, patience 5)，batch 128，最多 100 轮，20 轮不升早停，GPU 上混合精度，固定种子。
- 每轮保存：`log.csv`（epoch, train_loss, train_acc, val_loss, val_acc, lr, time），`last.pt`（续训用），`best.pt`（PublicTest 最优）。
- 命令示例：`python train.py --exp A2 --seed 0`，`python train.py --exp A2 --seed 0 --resume`。

## 5. 实验设计（按算力分阶段）

| 编号 | 配置 |
| --- | --- |
| A0 | 无增强、无 label smoothing |
| A1 | + 翻转与仿射 |
| A2 | + label smoothing 0.1 |
| A3 | + RandomErasing |
| A4 | 最佳配置 + 翻转 TTA（无需再训练） |
| A5 | 最佳配置 2~3 模型集成 |

- 第一轮：A0~A3 各 1 个种子 → 选前 2 名补到 3 个种子，报告 PublicTest 均值与范围。
- 先实测 T4 每轮耗时，再定是否缩短消融轮数（例如消融 60 轮，最终 100 轮）。
- 最终方案确定后，只跑一次 `evaluate.py`。

## 6. 训练前确认清单（全部通过才上 GPU）

1. 数据检查报告数字全对。
2. 单元测试：形状 (B,1,48,48)→(B,7)；归一化后均值≈0、方差≈1。
3. 隔离测试：train.py / select.py 源码与运行过程都不会读取 PrivateTest（自动断言）。
4. 小样本过拟合：512 张、关增强，训练准确率能接近 100%（证明管线无 bug）。
5. CPU 冒烟：2000 张跑 2 轮，log.csv、best.pt、last.pt 正常生成。
6. 续训测试：中途停止后 `--resume`，轮数与学习率接上。
7. 评估与前端一致性：同一批 PublicTest 图片，app.predict 与 evaluate 流程预测一致。
8. Colab 上 1 轮试跑，测耗时与显存。

## 7. Colab 运行方式（由 Hark 操作）

本地写好并测试 → 上传代码与 npz 到 Colab VM → 后台启动训练 → 定时查看 log.csv → 结束后下载 runs/ → 关闭 VM。
免费层可能中断，靠 `last.pt` 续训兜底。

## 8. 前端（Gradio）

- Gradio Blocks + 自定义主题（柔和配色、圆角卡片、中文界面）。
- 布局：左侧输入（上传 / 摄像头 / 示例图库），右侧结果（检测到的人脸框预览、48×48 输入预览、7 类概率条形图带表情图标、Top-1 大字结论）。
- 底部"模型信息"：模型结构、参数量、PrivateTest 准确率（读 `reports/final.json`，不在前端重新评估）。
- 预处理与训练完全一致（共用 `stats.json` 与 `dataset.preprocess`）；Haar 级联人脸检测，未检测到时整图缩放并提示。
- 示例图库：从 PublicTest 每类挑 1~2 张（不使用 PrivateTest）。
