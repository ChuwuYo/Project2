# 项目代码详解：FER2013 人脸表情识别

这份文档帮助你从头到尾理解项目：数据怎么进来、模型长什么样、怎么训练、怎么评估、前端怎么工作，以及验收时可能被问到的问题。建议边看边打开对应的源码文件。

---

## 1. 一句话概括

读取 FER2013 的 CSV（每行一张 48×48 灰度人脸 + 表情标签），用改造过的 ResNet18 从头训练 7 分类模型；只用 Training 训练、只用 PublicTest 做一切选择、PrivateTest 只做最终评估；最终把 6 个模型的预测概率取平均，PrivateTest 准确率 73.11%。

## 2. 整体流程

```
icml_face_data.csv
   │  dataset.py：解析 CSV → 缓存 data/fer2013.npz → 按 Usage 分成三个子集
   ▼
Training (28709) ──► train.py：数据增强 → ResNet18 → 交叉熵 → SGD 更新参数
PublicTest (3589) ─► train.py：每轮验证 → 保存最佳模型 best.pt、调学习率、早停、决定 TTA
                     evaluate.py --split PublicTest：比较单模型 / 集成，选出最终方案 → final_runs.txt
PrivateTest (3589) ► evaluate.py：最终方案只评估，输出准确率、分类报告、混淆矩阵
                     app.py：网页演示（摄像头 / 上传），推理方式与 evaluate.py 完全相同
```

## 3. 文件结构与职责

| 文件 | 作用 | 关键函数 / 内容 |
|---|---|---|
| `dataset.py` | 数据层：读取、划分、预处理、增强 | `load_split`、`build_transform`、`FERDataset`、`preprocess_face` |
| `model.py` | 模型结构 | `build_model` |
| `utils.py` | 公共工具 | `set_seed`、`make_loader`、`model_probs`、`predict_probs`、`load_model`、`load_runs`、`plot_curves` |
| `train.py` | 训练 | `EXPERIMENTS`、`train_one_epoch`、`validate`、`main` |
| `evaluate.py` | 评估（唯一读 PrivateTest） | `main` |
| `check_data.py` | 数据检查 | 数量、标签、均值方差、空白图、重复图 |
| `app.py` | 网页演示 | `detect_faces`、`align_crop`、`predict`、`annotate`、`build_app` |
| `tests/test_pipeline.py` | 自动测试 | 7 项检查 |
| `final_runs.txt` | 最终用哪些模型 | 6 行，每行一个模型目录 |

设计原则：每件事只在一个地方定义。比如预处理只在 `dataset.py` 里写一次，训练、评估、前端都调用它，所以三处不可能不一致。

## 4. 数据：`dataset.py`

### 4.1 CSV 格式

三列：`emotion`（0–6）、`Usage`（Training / PublicTest / PrivateTest）、`pixels`（2304 个用空格隔开的 0–255 数字，即 48×48）。

类别：0 愤怒、1 厌恶、2 恐惧、3 快乐、4 悲伤、5 惊讶、6 中性（`CLASSES`、`CLASSES_ZH`）。

### 4.2 读取与缓存

- `_parse_csv`：逐行读取，检查列名和每行像素个数是否为 2304，转成 `uint8` 的 48×48 数组。
- `load_all`：第一次解析 CSV 后用 `np.savez_compressed` 存成 `data/fer2013.npz`，以后直接读缓存（约 1 秒）。
- `load_split(split)`：全项目唯一的取数入口，按 `Usage` 筛出某个子集，返回 `(images, labels)`。

### 4.3 预处理（标准化）

```python
v2.ToDtype(torch.float32, scale=True)   # 0–255 → 0–1
v2.Normalize([MEAN], [STD])             # (x − 0.5077) / 0.2550
```

- `MEAN=0.5077`、`STD=0.2550` 只用 Training 的像素算出来。不用验证集和测试集统计，避免信息泄露。测试会重新计算并核对。
- 为什么要标准化：让输入大致在 0 附近、方差为 1，梯度更稳定，训练更快。

### 4.4 数据增强（只在训练时）

| 操作 | 作用 |
|---|---|
| `RandomHorizontalFlip` | 左右翻转，表情左右对称，等于数据量翻倍 |
| `RandomAffine(degrees=10, translate=0.1, scale=0.9–1.1)` | 小角度旋转、平移、缩放，模拟人脸位置和角度变化 |
| `RandomErasing(p=0.25)`（只 A3） | 随机遮挡一块，迫使模型不依赖局部 |

验证、测试、前端都不做增强，只做标准化（`build_transform(train=False)`）。

### 4.5 `FERDataset` 与 DataLoader

- `FERDataset` 把 `(N,48,48)` 数组变成 `(N,1,48,48)` 张量，`__getitem__` 返回一张变换后的图和标签。
- `utils.make_loader`：训练集 `shuffle=True` 并用固定种子的生成器（可复现）；验证/测试集固定顺序。

## 5. 模型：`model.py`

### 5.1 为什么改 ResNet18

标准 ResNet18 是给 224×224 彩色图设计的：第一层 7×7 卷积 stride 2，再接 maxpool，一开始就把图缩小 4 倍。48×48 的小图这样会损失太多细节。所以改三处：

1. `conv1`：输入通道 3→1（灰度），卷积核 7×7 stride 2 → 3×3 stride 1。
2. `maxpool`：去掉（换成 `nn.Identity()`）。
3. `fc`：`Dropout + Linear(512, 7)`，输出 7 类。

### 5.2 形状变化

| 层 | 输出形状 |
|---|---|
| 输入 | 1×48×48 |
| conv1 + BN + ReLU | 64×48×48 |
| layer1（2 个残差块） | 64×48×48 |
| layer2 | 128×24×24 |
| layer3 | 256×12×12 |
| layer4 | 512×6×6 |
| 全局平均池化 | 512 |
| Dropout + 全连接 | 7（logits） |

约 1100 万参数，从头训练，不用预训练权重。

### 5.3 残差块是什么

每个残差块：`输出 = ReLU(F(x) + x)`，其中 F 是两层 3×3 卷积 + BN。“+ x”这条捷径让梯度能直接往前传，网络更深也容易训练。尺寸变化时捷径用 1×1 卷积对齐通道和尺寸。

## 6. 训练：`train.py`

### 6.1 消融实验 `EXPERIMENTS`

| 名称 | 增强 | 标签平滑 | Dropout | RandomErasing |
|---|---|---|---|---|
| A0 | 否 | 0 | 0 | 否 |
| A1 | 是 | 0 | 0 | 否 |
| A2 | 是 | 0.1 | 0 | 否 |
| A3 | 是 | 0.1 | 0.4 | 是 |

每组只比上一组多一个改动，这样才能说清楚是哪个改动带来的变化。

### 6.2 损失函数：交叉熵（+ 标签平滑）

- `nn.CrossEntropyLoss` = softmax + 负对数似然，衡量预测概率和真实类别的差距。
- 标签平滑 0.1：把真实标签从 `[0,0,1,0,...]` 改成“正确类 0.9 + 其余平分 0.1”，防止模型过度自信。FER2013 标签本身有噪声，这样做理论上有帮助；我们的实验里 A2 和 A1 差别不大。

### 6.3 优化器与学习率

- SGD，momentum 0.9，Nesterov，初始学习率 0.01，weight decay 5e-4（L2 正则，防过拟合）。
- `ReduceLROnPlateau(mode="max", factor=0.5, patience=5)`：PublicTest 准确率连续 5 轮不涨，学习率减半。
- 早停：连续 20 轮不涨就停止，最多 100 轮。

### 6.4 每一轮做什么（`main` 中的循环）

1. `train_one_epoch`：遍历训练集，前向 → 算 loss → 反向传播 → 更新参数；同时统计训练 loss 和准确率。若 loss 出现 NaN 立即报错。
2. `validate`：在 PublicTest 上算 loss 和准确率（`torch.inference_mode()`，不算梯度）。
3. 调学习率，把这一轮的结果追加写入 `log.csv`。
4. 准确率创新高就保存 `best.pt`；每轮都保存 `last.pt`（含优化器等完整状态，用于 `--resume` 断点续训）。

### 6.5 混合精度（AMP）

GPU 上用 `torch.autocast` + `GradScaler`：部分计算用 float16，速度更快、显存更少；`GradScaler` 放大 loss 防止小梯度下溢。CPU 上自动关闭。

### 6.6 收尾：是否用翻转 TTA

训练结束后，用 `best.pt` 在 PublicTest 上分别算“不翻转”和“原图 + 翻转取平均”的准确率，后者更高就在 `summary.json` 里记 `use_tta: true`。评估和前端都读这个决定，所以这个选择也只依赖 PublicTest。

### 6.7 输出文件（`runs/<实验>_s<种子>/`）

`config.json`（全部参数）、`log.csv`（每轮 loss/acc/lr/耗时）、`curves.png`（曲线）、`best.pt`、`last.pt`、`summary.json`。

## 7. 评估：`evaluate.py`

1. 读取 `final_runs.txt`（或 `--runs` 指定的目录），加载每个模型的 `best.pt` 和 `summary.json`。
2. 对每个模型调用 `predict_probs` 得到 3589×7 的概率（按各自的 `use_tta` 决定是否翻转）。
3. 集成：6 个模型的概率取平均，`argmax` 得到预测类别。
4. 输出到 `reports/PrivateTest_ensemble6/`：
   - `metrics.json`：准确率、每个模型的单独准确率、各类召回率、混淆矩阵；
   - `classification_report.txt`：各类 precision / recall / F1；
   - `confusion_matrix.png`：混淆矩阵图（按行归一化）。

评估时没有反向传播、不改任何参数，模型和方案在评估前已经固定。

### 指标怎么理解

- 准确率 = 预测正确的数量 / 总数。
- Precision（精确率）：预测为某类的样本里，有多少真是这一类。
- Recall（召回率）：真实为某类的样本里，有多少被找出来。
- F1：precision 和 recall 的调和平均。
- 混淆矩阵：第 i 行第 j 列 = 真实是 i 类、被预测成 j 类的比例。我们的结果里快乐（F1 0.91）和惊讶（0.84）最好，恐惧（召回 0.51）最差，常被认成悲伤。

## 8. 方案选择（只用 PublicTest）

1. 阶段 1：A0–A3 各跑 1 个种子，PublicTest 前两名是 A1、A2。
2. 阶段 2：A1、A2 各补种子 1、2，得到 6 个模型。
3. 阶段 3：用 `evaluate.py --split PublicTest` 比较：最佳单模型 70.30%、A1×3 71.50%、A2×3 70.63%、A1+A2×6 71.52%，选最高的六模型集成，写入 `final_runs.txt`。
4. 阶段 4：只在这之后跑一次 PrivateTest：73.11%。

为什么集成更好：不同种子的模型犯的错误不完全一样，平均后随机误差相互抵消。

## 9. 数据检查：`check_data.py`

检查三个子集数量（28709 / 3589 / 3589）、标签范围 0–6、尺寸 48×48、均值方差，统计空白图和跨子集重复图，画类别分布和样例图。结果在 `reports/data_check/report.md`。

## 10. 网页演示：`app.py`

### 上传 / 拍照

1. `detect_faces`：用 OpenCV 自带的 YuNet 深度学习检测器找人脸，返回人脸框和双眼位置。
2. `align_crop`：按双眼连线把脸转正，以人脸中心截取 1.2 倍框大小的正方形，缩放到 48×48 灰度图（接近 FER2013 的裁剪方式）。
3. `preprocess_face` + `model_probs`：与评估完全相同的预处理和推理（6 模型集成 + TTA）。
4. 显示 7 类概率和“模型看到的 48×48 人脸”。

### 实时摄像头

采用 Gradio 官方文档的 “Unified Image” 写法：摄像头组件同时作为 stream 事件的输入和输出，每 0.1 秒取一帧，缩小到 320 宽检测人脸 → 所有人脸一次成批推理 → 直接在摄像头画面上画框写表情，下方显示最大那张脸的前三个表情。

页头的准确率直接读取 `reports/` 中 `evaluate.py` 生成的结果，前端不做任何评估。

## 12. 实验结果怎么讲

| 实验 | PublicTest | 结论 |
|---|---|---|
| A0 无增强 | 58.62% | 训练集 99.7%，严重过拟合 |
| A1 + 增强 | 69.19%（3 种子平均） | 提升约 10.6 个百分点，最关键 |
| A2 + 标签平滑 | 69.26%（3 种子平均） | 和 A1 差距在种子波动内，不能说更好 |
| A3 + Dropout + Erasing | 68.57%（1 种子） | 没有提升 |

讲法要点：结论必须有多次实验支撑；单次的小差距不足以说明方法更好（项目要求第五条）。

## 13. 验收可能被问到的问题

**为什么要分三个子集？** 训练集学参数；验证集选模型和调参；测试集模拟“没见过的数据”，只能用一次，否则测试准确率就不再是公正的估计。

**你们怎么保证没用测试集调参？** PrivateTest 只出现在 `evaluate.py` 里；训练脚本只读 Training 和 PublicTest；最佳模型、学习率调整、早停、TTA、集成全部按 PublicTest 决定；有自动测试检查训练过程从不读取 PrivateTest。

**为什么不用预训练模型？** ImageNet 预训练是 224×224 彩色自然图，和 48×48 灰度人脸差别大；从头训练在 FER2013 上也能达到 70% 以上，并且结构改动更容易解释。

**为什么去掉 maxpool、首层改 3×3？** 48×48 太小，原始结构一开始就缩小 4 倍到 12×12，丢失细节；改后最后一层特征图还有 6×6。

**过拟合怎么看出来、怎么解决？** A0 训练集准确率接近 100%，验证集停在 58%，差距巨大就是过拟合。加数据增强后差距明显缩小，验证集涨到约 69%。另外 weight decay、早停也在防止过拟合。

**loss 和准确率记录在哪？** 每轮写入 `log.csv`，并画成 `curves.png`。

**训练准确率为什么比验证集低（加增强后）？** 训练准确率是在增强（扰动）后的图像上算的，任务更难；验证集是原图。

**TTA 是什么？** 测试时增强：对原图和翻转图都预测一次，概率取平均。是否使用由每个模型在 PublicTest 上决定。

**集成是什么？为什么有用？** 多个模型的概率取平均。不同随机种子的模型错误不完全相同，平均后更稳定。PublicTest 上从 70.30%（单模型）提高到 71.52%。

**为什么 PrivateTest（73.11%）比 PublicTest（71.52%）高？** 两个子集图片不同，存在随机差异；我们没有在 PrivateTest 上做任何选择，所以这个数是真实的、一次性的结果。

**哪类最难？为什么？** 恐惧召回率只有 51%，常与悲伤、惊讶混淆，表情相似；厌恶训练样本只有 436 张，数据少。

**摄像头为什么有时认不准？** 模型只在 FER2013（低分辨率灰度、特定人群和光照）上训练，真实摄像头存在领域差异；73.11% 只代表在这个测试集上的表现。

**参考了什么？** LetheSec 的 FER2013 项目（ResNet 首层 3×3、去 maxpool、数据增强、标签平滑、测试时增强的思路），代码自己写；它用 PrivateTest 选模型，我们改为 PublicTest。来源写在 README 和 `references/references.yaml`。

**怎么复现？** `python train.py --exp A1 --seed 0` 训练；固定随机种子；`python evaluate.py` 评估；所有配置保存在每个 run 的 `config.json`。
